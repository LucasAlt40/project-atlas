## Design: `slugify` text utility

**Context read:** `package.json` is CommonJS (`"type": "commonjs"`), has no dependencies, and runs tests with `node --test`. `README.md` confirms this. There is no `src/` or `test/` directory yet. Git is clean on `atlas/exec-000001`.

### Module boundaries and architectural impact
- One leaf module with no imports and no shared state. It is a pure function, so it adds no coupling and no risk to existing code. The project currently has no other modules to reuse.

### Decisions for the Developer
1. **Pipeline order:** `String(text)` is not used. Check `typeof text !== 'string'` first and throw `TypeError`. Then `toLowerCase()`, then `normalize('NFD')` and remove `/\p{M}/gu` to strip diacritics. Then replace `/[^a-z0-9]+/g` with `-`, then trim leading and trailing `-`.
2. **Options:** Accept `options` as `undefined` or `null` and treat both as `{}`, e.g. `const { maxLength } = options ?? {}`.
3. **Invalid `maxLength`:** The spec does not cover it. Treat `undefined` as "no limit". For any other value that is not a positive integer (`0`, negatives, `2.5`, non-numbers), throw `RangeError`. Silently ignoring a bad limit would hide caller bugs.
4. **Truncation:** Only when `slug.length > maxLength`.
   - Take `head = slug.slice(0, maxLength + 1)`.
   - If `head` contains `-`, cut at its last `-`, which gives `head.slice(0, lastDash)`. The slug never starts with `-`, so `lastDash` is always greater than 0.
   - Otherwise hard-cut with `slug.slice(0, maxLength)`. In this branch the first `maxLength` characters contain no `-`, so the result cannot end with `-`.
   - Checked by hand against the examples: `'hello-big-world'` with 9 gives `'hello-big'`, with 8 gives `'hello'`, and `'supercalifragilistic'` with 5 gives `'super'`.
5. **Empty result:** Input with no `a-z0-9` characters, such as `'!!!'`, returns `''`. It does not throw.

### Files and contracts
- **New `src/slugify.js`:** `function slugify(text, options)` returns a string. Throws `TypeError` for a non-string `text` and `RangeError` for an invalid `maxLength`. The export object has exactly one key, `slugify`.
- **New `test/slugify.test.js`:** uses `const { test, describe } = require('node:test')` and `require('node:assert/strict')` or `require('node:assert')`, and requires `../src/slugify`. It covers:
  - the five spec examples;
  - accented input (`'Ação & Reação'`, `'Çà ü'`);
  - leading, trailing and repeated separators;
  - empty and symbol-only input;
  - `maxLength` exactly equal to, one less than, and far below the slug length;
  - no trailing `-` after any cut;
  - `TypeError` for a non-string, and `RangeError` for `0`, `-1` and `2.5`;
  - `Object.keys(require('../src/slugify'))` equals `['slugify']`.
