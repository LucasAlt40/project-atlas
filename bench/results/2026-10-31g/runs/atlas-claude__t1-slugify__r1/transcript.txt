1. **Pipeline order in `slugify(text, options)`:**
   - Throw `TypeError` unless `typeof text === 'string'`. This also rejects `null` and `undefined`.
   - Lowercase.
   - Decompose with `normalize('NFD')` and strip `/[\u0300-\u036f]/g`. This handles é, ç, ã, ü.

   - Trim leading and trailing `-`.
2. **`maxLength` handling:**
   - If `options` is absent, or `maxLength` is `undefined`, there is no limit.
   - Otherwise, if `maxLength` is not a positive integer, throw `RangeError`. The spec does not say what to do here, so this is my choice; the user can redirect it.

   - Otherwise let `cut = slug.slice(0, max)`. If `slug[max] !== '-'`, cut back to the last `-` in `cut`, if there is one. Then return `cut`.
   - Because the slug never has doubled dashes, this never ends in `-`. When the first word does not fit, the cut is hard.
   - Hand-checked against the examples: 'hello-big-world' with max 9 gives 'hello-big'. With max 8 it gives 'hello'. 'supercalifragilistic' with max 5 gives 'super'.
3. **Exports:** `module.exports = { slugify };` exactly, with `'use strict'` only if the surrounding style calls for it. There is no existing code to match, so plain CommonJS is fine.
