**What changed**

- **`src/orders.js`**: new `cancel(orderId, reason)`.
  - It checks `reason` first and throws a `TypeError` if it is not a string or is blank.
  - It throws `"... not found"` for an unknown id and `"... is already cancelled"` for a repeat cancel. Both happen before any stock moves or event fires.
  - Otherwise it restocks every item, sets `status` to `'cancelled'`, stores `reason` on the order, emits `order.cancelled` with `{ orderId, reason }`, and returns a copy of the order.
- **`src/reports.js`**: `revenue()` and `unitsSold(sku)` now skip cancelled orders.
