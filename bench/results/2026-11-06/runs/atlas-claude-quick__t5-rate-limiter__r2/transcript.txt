**Decisions the Developer must follow**
1. **Closure, not class.** `createLimiter` closes over `capacity`, `refillPerSecond`, `now`, `tokens` (float) and `last` (reference time in ms), and returns a plain object with the four methods. This is the smallest shape that meets the contract.
2. **Reference time is set at creation.** `last = now()` runs inside `createLimiter`. The tokens start at `capacity`.
3. **Refill rule.** `refill()` reads `t = now()`. If `t < last`, it sets `last = t` and adds nothing. Otherwise `tokens = min(capacity, tokens + (t - last) * refillPerSecond / 1000)` and `last = t`. Tokens are never lost on a backwards step.
4. **Float tolerance.** Use `const EPS = 1e-9` in every comparison, so drift from fractional refills cannot cause a false negative:
   - `available()` returns `Math.floor(tokens + EPS)`.
   - `tryRemove` succeeds when `tokens + EPS >= n`.
   - `msUntil` computes `deficit = n - tokens`. If `deficit <= EPS` it returns 0. Otherwise it returns `Math.ceil(deficit * 1000 / refillPerSecond)`.
5. **Argument validation.**
   - `options` missing is treated as `{}`, so the missing `capacity` raises a `RangeError`.
   - `capacity`: `Number.isInteger(c) && c > 0`, else `RangeError`.
   - `refillPerSecond`: `typeof r === 'number' && Number.isFinite(r) && r > 0`, else `RangeError`. This rejects NaN and Infinity.
   - `n` (default 1 when `undefined`): `Number.isInteger(n) && n > 0 && n <= capacity`, else `RangeError`. Used by both `tryRemove` and `msUntil`.
   - `now`: if `undefined`, use `Date.now`. If present and not a function, throw `TypeError`. The task does not specify this case; see the question below.
6. **`reset()`** calls `refill()` first, so the reference time moves forward, then sets `tokens = capacity`.
7. **Style.** Follow the project's CommonJS style. Keep the code small, with one helper for `n` validation and no extra abstractions.

**Files and contracts**
- `src/limiter.js` (new): exports exactly `{ createLimiter }`.
- `test/limiter.test.js` (new): uses an injected fake clock, e.g. `let t = 0; const now = () => t;`.
- Public contract: `createLimiter(options)` returns `{ tryRemove(n=1), available(), msUntil(n=1), reset() }`, with the semantics and `RangeError`s from the task.

- `tryRemove(n)` is atomic: it removes `n` tokens only when at least `n` are available.
- Refill over time with integer rate: capacity 2, rate 1. Drain, advance 500 ms (0 available), advance 500 ms more (1 available).
- Fractional rate 0.5: after 1000 ms, `available()` is 0; after 2000 ms, it is 1.
- Capping: after a long idle period, `available()` equals `capacity`.
