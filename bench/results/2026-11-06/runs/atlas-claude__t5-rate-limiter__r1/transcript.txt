# Plan: token-bucket limiter (`src/limiter.js`) and tests

## Goals
- Provide `createLimiter({ capacity, refillPerSecond, now })` as a CommonJS token bucket, exported as `module.exports = { createLimiter }`.
- Validate inputs strictly and throw `RangeError` on bad values.
- Behave deterministically under an injected clock, including when the clock goes backwards.

## In scope
- New file `src/limiter.js`.
- New file `test/limiter.test.js` using `node:test` and `node:assert`.

## Out of scope

## Design
**State (closure, not exposed):**
- `capacity` (integer), `refillPerSecond` (number).
- `tokens`: a float in `[0, capacity]`.
- `last`: the last time seen, in ms.

**Clock and refill (single private `refill()`):**
```
const t = now();
if (t > last) tokens = Math.min(capacity, tokens + ((t - last) * refillPerSecond) / 1000);
last = t;   // also covers a backwards clock: reference moves, nothing added or lost
```
Multiply before dividing by 1000 to keep float error small.

**Validation:**
- `createLimiter(options = {})`. Defaulting to `{}` means a missing `options` produces the spec's `RangeError` for `capacity`, not a `TypeError`.
- `capacity`: `Number.isInteger(c) && c > 0`, else `RangeError`.
- `refillPerSecond`: `typeof === 'number' && Number.isFinite(r) && r > 0`, else `RangeError`.
- `now`: defaults to `Date.now`. If provided and not a function, throw `TypeError`. This is my choice; the spec does not cover it.
- Count `n` (in `tryRemove` and `msUntil`): `Number.isInteger(n) && n > 0`, else `RangeError`. Then if `n > capacity`, `RangeError`.

**Precision:** use one constant `EPS = 1e-9` in every comparison and rounding, so the same rule applies everywhere:
- `available()`: `Math.floor(tokens + EPS)`.
- `tryRemove(n)`: succeed when `tokens + EPS >= n`. On success, `tokens = Math.max(0, tokens - n)`.
- `msUntil(n)`: refill; if `tokens + EPS >= n` return 0; else `Math.ceil((n - tokens) * 1000 / refillPerSecond - EPS)`.
- This keeps the promise that after `msUntil(n)` ms, `tryRemove(n)` succeeds.

**Methods:**
- Constructor: `last = now()`, `tokens = capacity` (starts full).
- `tryRemove(n = 1)`: validate, refill, then check and remove as above. On failure, nothing is removed.
- `available()`: refill, then floor as above.
- `msUntil(n = 1)`: validate, refill, then compute as above.
- `reset()`: `tokens = capacity; last = now();`.
