### Design of `src/slugify.js`
1. **Validate `text`:** `if (typeof text !== 'string') throw new TypeError(...)`.
2. **Normalize, in this order:**
   - `text.toLowerCase()` first. Lowercasing `İ` yields `i` plus U+0307, and that mark must be stripped too.
   - `.normalize('NFD').replace(/[\u0300-\u036f]/g, '')` removes the diacritics (`é`→`e`, `ç`→`c`, `ã`→`a`, `ü`→`u`).
   - `.replace(/[^a-z0-9]+/g, '-')` collapses each run of other characters into one `-`.
   - `.replace(/^-|-$/g, '')` trims. After collapsing there can be at most one dash at each end, so this is enough.
3. **`maxLength`:** `options` may be omitted. If `options.maxLength` is `undefined`, there is no limit. Otherwise it must be a positive integer, or the function throws `RangeError`. Then truncate as follows, with `slug` being the normalized string:
   ```js
   if (slug.length <= max) return slug;
   if (slug[max] === '-') return slug.slice(0, max);     // cut lands exactly on a word boundary
   const cut = slug.lastIndexOf('-', max - 1);
   return cut > 0 ? slug.slice(0, cut) : slug.slice(0, max); // else the first word is too long: hard cut
   ```
   Checked by hand against the examples: `'hello-big-world'` with 9 → `'hello-big'`; with 8 → `'hello'`; `'supercalifragilistic'` with 5 → `'super'`. The result never ends with `-`, because a dash is only kept at `slice(0, max)` when it is at index `max`, and the hard cut contains no dash.
4. Keep the code short. Use no classes, no helper module, and comments only where the truncation logic needs one.

### Decisions the Developer must follow
- Lowercase before the NFD step (see above).
- Use `NFD` and not `NFKD`. Compatibility forms such as `ﬁ` are not in the spec.
- Characters with no decomposition (`ß`, `ø`, `æ`, `ł`) become `-` under rule 3. For example, `'Straße'` gives `'stra-e'`. This follows the literal rules, so it is not a bug.
- An invalid `maxLength` (0, negative, non-integer, non-number) throws `RangeError`. The spec does not cover this, so it is my reading.
- Empty or symbol-only input returns `''`.
