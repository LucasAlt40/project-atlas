1. **High — Security:** HTML escaping is incomplete.

   - **File:** `src/users.js:17-20`
   - **Why:** `String.replace()` with string arguments replaces only the first occurrence of each character. Input such as `<img><script>alert(1)</script>` remains partially unescaped and `userRow()` emits executable markup.

   - **File:** `src/users.js:3-6`
   - **Why:** The contract states page `1` is the first page, but `start = page * size` makes page 1 start at index `size`. Verified: `paginate([1,2,3,4], 1, 2)` returns `[3,4]`.

   - **File:** `src/users.js:10-12`
   - **Why:** Subtracting only birth years classifies someone born December 31, 2008 as an adult on June 1, 2026, although they are still 17.
   - **Recommendation:** Compare the current date with the person’s birthday in the current year, including month and day.
