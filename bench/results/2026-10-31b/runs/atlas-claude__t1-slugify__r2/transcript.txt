**Steps for the Developer:**
1. Type check first: if `text` is not a string, `throw new TypeError(...)`.
2. Normalise: `text.toLowerCase().normalize('NFD').replace(/[\u0300-\u036f]/g, '')`. NFD splits `é`, `ç`, `ã`, `ü` into base letter plus combining mark, and the regex strips the marks.
3. Collapse separators: `.replace(/[^a-z0-9]+/g, '-')`, then trim edges with `.replace(/^-+|-+$/g, '')`.
4. Apply `maxLength` if it is set. Given `slug` already clean:
   - If `slug.length <= max`, return `slug`.
   - Else if `slug[max] === '-'`, the first `max` characters end exactly at a word boundary: return `slug.slice(0, max)`.
   - Else `const dash = slug.slice(0, max).lastIndexOf('-')`. If `dash > 0`, return `slug.slice(0, dash)`. Otherwise the first word does not fit, so return `slug.slice(0, max)` (hard cut).
   - Because the slug has no leading dash and no runs of dashes, none of these branches can end with `-`.
5. Options: `const max = options?.maxLength`. If it is `undefined`, there is no limit. Otherwise it must be an integer `>= 1`, else throw `RangeError`. The task does not specify this, so the choice is mine and is listed under decisions.
6. Empty or punctuation-only input returns `''`. It does not throw.

**Files:**
- New: `src/slugify.js`, with `module.exports = { slugify };` and no other exports.
- New: `test/slugify.test.js`, which does `require('../src/slugify')`, `require('node:test')`, `require('node:assert')`.

**Test cases:**

- **Empty result:** return `''`, do not throw.
- **Invalid `maxLength`:** `RangeError` (decision by me, since the task is silent). Missing `maxLength` means no limit.
- **Test runner:** `node:test` and `node:assert`, as the task says. Do not add dependencies.

- **Non-ASCII letters:** a user expecting `ß` → `ss` will get `-`. This is per the spec's own rule 3 but may surprise users.
- **Node version:** `node:test` needs Node 18 or later, and optional chaining needs Node 14 or later. The project declares no `engines` field, so this is an assumption to note.
