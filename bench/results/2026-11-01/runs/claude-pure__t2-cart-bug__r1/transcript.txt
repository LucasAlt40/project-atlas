I fixed `src/cart.js` and added a regression test, but I could not run the test suite. Every attempt to run `node --test` was blocked with "requires approval," so the tests are unverified. I checked the new expectations by hand against the code.

**Root causes in `src/cart.js`:**
- **Quantity ignored:** the loop summed `item.price` and never multiplied by `item.qty`. That's why 3 × 19.90 showed 19.9.
- **Percent coupon inverted:** `sum * value / 100` computed the discount amount, not the price after discount. That's why OFF20 on 100 gave 20.
- **Fixed coupon unclamped:** TENOFF subtracted from the subtotal with no floor at zero, so a 5.00 cart gave -5.
- **Float drift:** the total was never rounded, which produced values like 0.30000000000000004.
- **Coupon lookup:** `COUPONS[couponCode]` also matches inherited keys such as `toString`. I changed it to an own-property check so unknown codes are ignored.

**The fix:** the total is now computed in integer cents. Each line is `Math.round(price * 100) * qty`. The coupon is applied in cents, the result is floored at 0, and it's returned as cents / 100. `module.exports = { total }` and the signature are unchanged.

**Regression test** (`test/cart.test.js`): covers 19.9 × 3 = 59.7, TENOFF on 5.00 = 0, OFF20 on 100 = 80, 0.1 + 0.2 = 0.3, an unknown coupon ignored, and `toString` ignored. The existing `single item` and `empty cart` tests are untouched.

To confirm, run `npm test` in the project root. I expect all three tests to pass.
