I added `src/slugify.js` and `test/slugify.test.js`, and `npm test` passes all 10 tests.

- **Module:** `slugify(text, options = {})` lowercases the text and strips diacritics with NFD normalisation. It then turns each run of non-`a-z0-9` characters into one `-` and trims dashes from both ends. If `maxLength` is set, it cuts at the last `-` that fits, or cuts the first word hard if no dash fits. It throws a `TypeError` for non-strings and exports `module.exports = { slugify }`.
- **Tests:** they cover all five spec examples, the separator and trimming rules, a dash landing exactly at `maxLength`, the hard cut, and the `TypeError`. They use `node:test` and `node:assert`.
- **Choices I made:**
  - I used `options = {}` as the default. Passing `null` as options throws a `TypeError` from destructuring, which I left alone.
  - I did not validate `maxLength` beyond checking that it is set, because the spec only says it is a positive integer.
