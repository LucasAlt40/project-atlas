I fixed the bugs in `src/cart.js` and added a regression test, but I could not run the test suite. Both `node --test` and `npm test` were blocked by a permission prompt in this non-interactive session, so the test results are checked by hand, not by running them.

**Root causes in `src/cart.js`:**
1. **Quantity ignored.** The loop added `item.price` and never multiplied by `item.qty`. That is why 3 × 19.90 showed 19.9.
2. **Percent coupon inverted.** `sum * value / 100` computed the discount amount, not the discounted total. That is why 100 with OFF20 showed 20.
3. **Fixed coupon could go negative.** `sum - value` was never clamped at zero. That is why 5.00 with TENOFF showed -5.
4. **No rounding.** The raw float was returned, which produced values like 0.30000000000000004.
5. **Unknown coupon names.** `COUPONS[couponCode]` also matched inherited properties such as `constructor`. Those would produce NaN.

**The fix:**
- Sum `item.price * item.qty`.
- Apply a percent coupon as `sum - sum * value / 100`.
- Use `Object.prototype.hasOwnProperty.call` to look up coupons, so only real coupon codes apply.
- Return `Math.round(Math.max(0, sum) * 100) / 100`, which clamps at zero and rounds to cents.
- The `module.exports = { total }` API is unchanged.

**Regression test** in `test/cart.test.js` covers quantity (19.9 × 3 → 59.7), OFF20 on 100 → 80, TENOFF on 5 → 0, unknown and inherited coupon names → ignored, and cent rounding (0.1 × 3 → 0.3). The two existing tests are unchanged.
