**Changes**

- **`src/inventory.js`**: added `restock(sku, qty)`, which adds stock back. Nothing else in the inventory API could return stock.
- **`src/orders.js`**: added `cancel(orderId, reason)`. It checks the reason first and throws a `TypeError` if it is not a non-empty string. It then looks up the order and throws `not found` or `already cancelled` as specified. Only after those checks does it restock the items, set `status` to `'cancelled'`, store `reason` on the order, emit `order.cancelled` with `{ orderId, reason }`, and return a copy of the order.
- **`src/reports.js`**: `revenue()` and `unitsSold(sku)` now skip cancelled orders.
- **`test/cancel.test.js`** (new): covers stock returning and the status and reason being kept, the single event, the not-found and already-cancelled errors (with no change on the second cancel), invalid reasons, and reports excluding cancelled orders. The existing `test/shop.test.js` is untouched.

**Choices you may want to change**

- A reason of only whitespace counts as empty and throws `TypeError`.
- The reason is checked before the lookup, so a bad reason on a missing order throws `TypeError`, not `not found`.
- The reason is stored as a new `reason` field on the order.
