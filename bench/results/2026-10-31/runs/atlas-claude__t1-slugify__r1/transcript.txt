### Findings, by severity

**1. Low: negative `maxLength` returns a result longer than the limit.**

**2. Low: `maxLength: null` silently returns an empty string.**
- Repro: `slugify('hello big world', { maxLength: null })`. `null` coerces to 0 in `slug.length <= null`, so the result is `''`.
- Same root cause as finding 1: no validation of `maxLength`. `maxLength: '9'` happens to work through string coercion, but that is accidental.
- File: `src/slugify.js:14–15`.

**3. Low: `options: null` throws an unclear error.**

- File: `src/slugify.js:1, 14`. Fix: `const { maxLength } = options || {};`.

**4. Low, theoretical: combining marks outside U+0300–U+036F are not stripped.**

- Realistic impact is small, since most Latin text uses the U+0300 block. File: `src/slugify.js:9`.

**5. Info: non-decomposable Latin letters become a dash.**
- `straße` → `stra-e`, `ø` / `æ` → `-`. This is the decision recorded in the workflow ("no transliteration"), so it is not a defect. But no test pins it, so a future change to transliteration would pass silently.
- Suggested test: `assert.strictEqual(slugify('straße'), 'stra-e')`.
