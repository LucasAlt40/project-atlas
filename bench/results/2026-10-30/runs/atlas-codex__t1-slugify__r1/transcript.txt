## Architecture

The project currently contains only a CommonJS package contract and no source or test modules:

- `package.json`: `"type": "commonjs"` and `npm test` runs `node --test`.
- `src/slugify.js`: new standalone utility with no dependencies.
- `test/slugify.test.js`: black-box tests against the exported API.

Architectural impact is minimal: one pure text transformation utility and one isolated test module. The main maintainability risk is implementing `maxLength` against normalized word boundaries so ordinary truncation never splits words, while still hard-cutting an overlong first word.

## Developer decisions

- Validate `text` before processing and throw `TypeError` for non-strings.
- Use Unicode decomposition plus combining-mark removal for accents and diacritics.
- Lowercase before converting non-`a-z0-9` runs to one `-`.
- Trim leading and trailing separators.
- For `maxLength`, keep the longest complete word sequence that fits; hard-cut only when the first word exceeds the limit.
- Preserve the exact export shape: `module.exports = { slugify }`.
- Do not add dependencies or modify unrelated files.
