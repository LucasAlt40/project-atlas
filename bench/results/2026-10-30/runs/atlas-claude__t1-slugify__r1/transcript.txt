## Goals
Add a dependency-free CommonJS helper `slugify(text, options)` that turns arbitrary text into a URL-safe slug. An optional `maxLength` cuts on word boundaries. Add `node:test` tests for it.

## Scope

- **Out:** `package.json`, `README.md`, any other file, any dependency, and the existing `node --test` setup.
- **Out (decided):** Non-ASCII letters with no ASCII decomposition (`ß`, `ø`, `ł`, CJK) are not transliterated. They are removed like any other character and act as separators.

## Project context

## Design

### `slugify(text, options = {})`
1. **Type check:** if `typeof text !== 'string'`, throw `TypeError`.
2. **Options check:** if `options.maxLength` is set and is not a positive integer (`Number.isInteger(n) && n > 0`), throw `RangeError`. The task does not define this case. Throwing is safer than silently ignoring a bad limit. This is the one decision the Developer should confirm.
3. **Accent removal:** `text.normalize('NFD').replace(/[\u0300-\u036f]/g, '')`. This turns `é ç ã ü` into `e c a u`.
4. **Lowercase:** `.toLowerCase()`.
5. **Collapse separators:** `.replace(/[^a-z0-9]+/g, '-')`. Each run becomes one `-`.
6. **Trim:** `.replace(/^-+|-+$/g, '')`.
7. **Truncate**, only when `maxLength` is set and `slug.length > maxLength`:
   - `head = slug.slice(0, max)`.
   - If `slug.charAt(max) === '-'`, the cut is on a word boundary, so return `head`.
   - Otherwise `idx = head.lastIndexOf('-')`. If `idx > 0`, return `head.slice(0, idx)`. This drops the partial word and any trailing dash.
   - Otherwise the first word alone is too long, so return `head` (hard cut).
   - The result never starts with `-` (step 6, and `idx > 0`). It never ends with `-`, because a trailing dash in `head` only occurs when `charAt(max) !== '-'`, and then `lastIndexOf` removes it.

Hand-checked against the task examples:
- `'hello big world'`, max 9: slug `hello-big-world`, `charAt(9)` is `-`, result `hello-big`.
- max 8: `head` is `hello-bi`, `charAt(8)` is `g`, `lastIndexOf('-')` is 5, result `hello`.
- `'supercalifragilistic'`, max 5: no `-` in `super`, hard cut, result `super`.
- `'  Olá, Mundo!  '` gives `ola-mundo`. `'Ação & Reação'` gives `acao-reacao`.

### Export
`module.exports = { slugify };` exactly.

### Not added
No helper module, class, transliteration map, or extra export. At most two small private helpers, if the Developer finds them clearer.
