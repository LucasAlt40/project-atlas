**1. `paginate` skips the first page (line 5, correctness)**
- **Why it's wrong:** The doc comment says `page` is 1-based, but `start = page * size` treats it as 0-based. `paginate(items, 1, 10)` starts at index 10, so the first ten items never appear. Page 0 quietly returns the first page, which the doc comment doesn't allow.
- **Fix:** `const start = (page - 1) * size;` and reject `page < 1` (throw or clamp) so bad input fails visibly.

**2. `escapeHtml` only escapes the first occurrence of each character (lines 17–20, security)**
- **Why it's wrong:** `String.prototype.replace` with a string pattern replaces only the first match. The input `<a><img onerror=alert(1) src=x></a>` becomes `&lt;a>&lt;img onerror=alert(1) src=x&gt;</a>`. The second `<` is still raw, so `<img ... onerror=...>` is live markup. `userRow` passes `user.name` through this function, so any user with such a name can inject script into the users table. Two related gaps: `&` is not escaped first, so the replacements can't be composed safely, and `"` and `'` are not escaped, so the output is unsafe inside attribute values.
- **Fix:** Use global regexes and escape `&` first:
  ```js
  return String(text)
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;')
    .replace(/'/g, '&#39;');
  ```
  Ideally, use a vetted library or the templating engine's auto-escaping instead of hand-rolled escaping.

**3. `isAdult` compares years only (lines 11–12, correctness)**
- **Why it's wrong:** Subtracting years ignores the month and day. Someone born 2008-12-31 is 17 on 2026-01-01, but `2026 - 2008 = 18`, so the function returns `true`. It is wrong for roughly the first 364 days of each year for anyone whose 18th birthday hasn't yet arrived.
- **Fix:** Subtract one if the birthday hasn't happened yet:
  ```js
  let age = today.getFullYear() - birthDate.getFullYear();
  const m = today.getMonth() - birthDate.getMonth();
  if (m < 0 || (m === 0 && today.getDate() < birthDate.getDate())) age--;
  return age >= 18;
  ```

**4. `paginate` does not validate `size` (line 5, minor)**
- **Why it's wrong:** A `size` of `0` or a negative value gives an empty or unexpected slice with no error. A non-numeric `page` becomes `NaN`, and `slice(NaN, NaN)` returns the whole array, so a bad query parameter returns everything.
- **Fix:** Check that `page` and `size` are positive integers before slicing.
