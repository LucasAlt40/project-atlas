Recuperação de senha markdown
  1. Adicionar endpoint POST /auth/forgot-password para receber e validar e-mail
  2. Gerar token criptográfico único com expiração de 15 minutos persistido em Redis
  3. Disparar template transacional de e-mail com link assinado contendo o token
  4. Adicionar endpoint POST /auth/reset-password para atualizar senha e invalidar sessões
  5. Criar testes unitários para ciclo completo e cenários de token expirado
