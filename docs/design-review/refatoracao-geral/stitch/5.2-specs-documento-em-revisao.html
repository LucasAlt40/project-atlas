SEC-AUTH-091

Requisito: Pedir recuperação

Garante que clientes e colaboradores da frota possam recuperar credenciais de acesso corporativo com garantias criptográficas e retenção controlada de tokens para mitigar ataques de enumeração de conta.

checklist Cenário: e-mail cadastrado

  • QUANDO o usuário informar um endereço de e-mail válido existente na base de dados ativa do ERP;
  • ENTÃO o sistema gera um token assinado (HMAC-SHA256) com expiração estrita de 15 minutos mantido exclusivamente em memória/cache Redis;
  • ENTÃO envia um link único de redefinição transacional para a caixa postal informada via fila de e-mail do microserviço de mensageria;
  • ENTÃO registra evento de auditoria AUTH_RESET_REQUESTED sem expor o token criptográfico nos logs estruturados da aplicação.

Contrato de Payload e Evento

// POST /api/v2/auth/password-reset/request
{
"email": "operador@transport-erp.internal",
"client_ip": "192.168.1.120",
"origin_device": "native-desktop-tauri",
"ttl_seconds": 900
}
Diretriz de Segurança Restritiva
Respostas HTTP para e-mails não cadastrados devem manter latência idêntica (tempo constante) e retornar mensagem genérica para mitigar User Enumeration Attacks.
Validações Aprovado

Nenhum problema na estrutura.
